# Documentation

Welcome to the docs section of **Tanmay.dev**.

This space is a collection of deep-dive guides, checklists, and reference notes around cloud infrastructure, GPUs, security, and cost optimization.

## What you can explore

- **[Running GPUs in 2026](/docs/running-gpus-in-2026)**  
  A practical, provider-by-provider guide for spinning up NVIDIA GPU instances (or your local machine), understanding quotas, and avoiding surprise bills.

- **[Cost Optimization Playbook](/docs/cost-optimization-playbook)**  
  Step-by-step guides for reducing AWS costs across compute, databases, storage, networking, and monitoring.

- **[EKS Security Hardening](/docs/eks-security-hardening)**  
  A layered approach to securing EKS clusters — from Bottlerocket nodes to CI/CD pipeline scanning.

- **[AWS Account & Access Setup](/docs/aws-account-setup)**  
  Checklists for setting up a production-grade AWS account with SSO, permission sets, EKS, and governance policies.

## How to read this

- Start with the topic that matches your current need.
- Each section is self-contained — you do not need to read them in order.
- Blog posts tell the story ("what I did and why"); docs tell you how to do it yourself.
